FIDAL NOTAIRESATTENTE

Écran d'attente riche pour les générations longues. Un script, quatre contenus mis en cache chacun à son rythme, quatre radios, et une trame parcellaire qui se colorise au rythme du traitement.

Intégration dans un outil

<script src="https://ATTENTE_DOMAINE/attente.js?v=1"></script>
<script>
  ATTENTE.demarrer({
    titre: "Dossier complet",
    sousTitre: "PAINT — extraits officiels",
    source: "#spinmsg"          // le module lit « 12 sur 30 » ou « 43 % » tout seul
    // trame: svgDuParcellaire  // facultatif : sinon trame générique
  });
  // … traitement long …
  ATTENTE.terminer();           // ou ATTENTE.echec("message") : bandeau, le
                                // contenu continue de tourner
</script>
